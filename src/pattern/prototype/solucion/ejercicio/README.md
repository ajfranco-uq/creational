# Ejercicio

## Configuración de una aplicación

Una empresa tiene diferentes configuraciones para sus ambientes de desarrollo, pruebas y producción.

Una configuración contiene:


```
Nombre de la empresa.
Moneda.
Impuesto.
Ruta de reportes.
URL del servidor.
Puerto.
Activar logs.
Activar notificaciones.

```

* La empresa ya tiene algunas configuraciones base correctamente configuradas. A partir de estas configuraciones se necesitan crear nuevas configuraciones similares, pero realizando pequeños cambios. 
* Por ejemplo, a partir de una configuración de producción se puede crear una nueva configuración para un servidor diferente, manteniendo todos los demás valores. 
* Se desea poder crear una configuración nueva a partir de una configuración existente, modificando únicamente los valores que sean necesarios.

```
Analice el problema, realice el diagrama UML con sus relaciones, aplique le patrón Prototype e implementarlo en Java.
```
